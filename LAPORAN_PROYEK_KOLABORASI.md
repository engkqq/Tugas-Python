## **B. DESKRIPSI PROYEK**

Dalam proyek ini, kalian diminta untuk merancang dan membangun sebuah aplikasi berbasis Python sederhana yang mengintegrasikan konsep pemrograman dengan database untuk kebutuhan industri atau bisnis. Aplikasi yang dibuat harus memiliki fungsi CRUD (Create, Read, Update, Delete) dan dapat terhubung dengan database localhost menggunakan MySQL.

Selain pengembangan aplikasi, peserta didik juga dituntut untuk menyusun laporan dokumentasi ilmiah yang komprehensif mengenai aplikasi yang telah dibuat, termasuk analisis, implementasi, dan hasil pengujian.

---

## **C. PERINTAH & TUGAS PROYEK**

### **1. Tugas Pemrograman Python (Mata Pelajaran Informatika)**

Buatlah sebuah aplikasi Python yang memenuhi kriteria berikut:

✅ **Konsep Dasar Python:**
   - Menggunakan Variable, Type Data, Operator, Perulangan (if-else, for, while)
   - Menggunakan Function (KA) dan Function dengan Return Type
   - Implementasi Pilihan Menu (if-else) dan Percabangan (if-else, elif-else, if-else nested, dan switch/match)

✅ **Fitur Terapan Aplikasi (PB: satu tabel minimal dengan 5 kolom data):**
   - **Tema A: Aplikasi Manajemen Karyawan** (Mapel KKA)
     - Tambah Karyawan, Lihat Data, Cari Karyawan, Update Status, Hapus Data, Statistik Gaji
   
   - **Tema B: Sistem Inventaris & POS** (Point of Sale Toko Kelontong)
     - Manajemen Barang, Input Penjualan, Update Stok, Laporan Penjualan, Alert Stok Kurang
   
   - **Tema Lainnya:** Sistem Peserta Didik, Sistem Nilai, Manajemen Proyek, dll

✅ **Integrasi Database MySQL:**
   - Koneksi ke database `rizkima-python` di localhost
   - Pembuatan tabel otomatis atau manual
   - Implementasi CRUD Operations
   - Query sederhana dengan WHERE, JOIN, dan aggregation (SUM, AVG, COUNT)

✅ **User Interface:**
   - Menu interaktif menggunakan input/output sederhana
   - Validasi input data
   - Error handling yang tepat
   - Feedback user yang jelas
